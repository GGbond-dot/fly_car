## 数据流向图

### 1. 位置控制数据流

```
目标位置设定
     ↓
[x_cm, y_cm, z_cm, yaw_deg]
     ↓
/target_position (Float32MultiArray)
     ↓
┌─────────────────────────┐
│  PositionPIDController  │
│  ┌──────────────────┐   │
│  │ 获取当前位置(TF) │   │
│  │ map → laser_link │   │
│  └──────────────────┘   │
│          ↓              │
│  ┌──────────────────┐   │
│  │  计算误差         │   │
│  │  error = target  │   │
│  │        - current │   │
│  └──────────────────┘   │
│          ↓              │
│  ┌──────────────────┐   │
│  │ PID计算4个控制量 │   │
│  │ - pid_x          │   │
│  │ - pid_y          │   │
│  │ - pid_z          │   │
│  │ - pid_yaw        │   │
│  └──────────────────┘   │
└─────────────────────────┘
     ↓
/target_velocity [vx, vy, vz, vyaw]
     ↓
UartToStm32 节点
     ↓
麦克纳姆轮速度计算
     ↓
[v1, v2, v3, v4]
     ↓
串口发送到STM32
     ↓
电机驱动板执行
```

### 2. 反馈数据流

```
传感器(STM32)
     ↓
高度/姿态数据
     ↓
串口接收
     ↓
UartToStm32解析
     ↓
/height (Int16)
     ↓

     ↓
用于Z轴控制
```

## PID控制详细流程

```
┌─────────────────────────────────────────────────────────┐
│                    PID控制器                             │
│                                                         │
│  输入: setpoint (目标值), measured_value (测量值), dt    │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤1: 计算误差                              │        │
│  │ error = setpoint - measured_value           │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤2: 死区处理                              │        │
│  │ if |error| < deadzone:                      │        │
│  │     error = 0                               │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤3: 计算比例项                            │        │
│  │ P = Kp × error                              │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤4: 计算积分项                            │        │
│  │ integral += error × dt                      │        │
│  │ integral = clamp(integral, -limit, +limit)  │        │
│  │ I = Ki × integral                           │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤5: 计算微分项                            │        │
│  │ derivative = (error - prev_error) / dt      │        │
│  │ derivative_filtered = α×prev_d + (1-α)×d    │        │
│  │ D = Kd × derivative_filtered                │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤6: 求和                                  │        │
│  │ output = P + I + D                          │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤7: 输出限幅                              │        │
│  │ output = clamp(output, min, max)            │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│  ┌─────────────────────────────────────────────┐        │
│  │ 步骤8: 抗饱和处理                            │        │
│  │ if output达到限幅且error同向:                │        │
│  │     积分项回退                               │        │
│  └─────────────────────────────────────────────┘        │
│                    ↓                                    │
│                 返回output                              │
└─────────────────────────────────────────────────────────┘
```

## 坐标系变换图示

### 全局坐标系到本体坐标系

```
        全局坐标系 (map/odom)
              ↑ y_global
              │
              │
              └────→ x_global


        机器人本体坐标系
              ↑ y_local
              │
          ╔═══╪═══╗
          ║   │   ║  ← 机器人
          ╚═══╧═══╝
              └────→ x_local

        机器人朝向角度: θ (yaw)


变换公式:
┌─────────┐   ┌──────────────────────┐   ┌──────────┐
│ x_local │ = │  cos(θ)    sin(θ)   │ × │ x_global │
│ y_local │   │ -sin(θ)    cos(θ)   │   │ y_global │
└─────────┘   └──────────────────────┘   └──────────┘

例: 如果机器人朝向θ=90° (向左), 全局向前(x_global=1)会变成本体向左(y_local=1)
```

## 麦克纳姆轮配置图

```
         前方 (Forward)
    ╔════════════════════╗
    ║                    ║
    ║  1 ↗        ↖ 2   ║
    ║  ╱            ╲   ║
    ║                    ║
    ║                    ║
    ║  ╲            ╱   ║
    ║  4 ↖        ↗ 3   ║
    ║                    ║
    ╚════════════════════╝

轮子滚子方向:
1: 右前 (↗)  -  左前侧有滚子
2: 左前 (↖)  -  右前侧有滚子  
3: 右后 (↗)  -  左后侧有滚子
4: 左后 (↖)  -  右后侧有滚子

参数定义:
lx = wheelbase/2   (前后轮距的一半)
ly = track_width/2 (左右轮距的一半)

速度公式:
v1 = vx - vy - ω(lx+ly)
v2 = vx + vy - ω(lx+ly)
v3 = vx + vy + ω(lx+ly)
v4 = vx - vy + ω(lx+ly)
```

### 运动示例

```
1. 前进 (vx>0, vy=0, ω=0)
   所有轮子同向同速
   ↗ ↖
   ↖ ↗

2. 左移 (vx=0, vy>0, ω=0)
   对角线轮子反向
   ↙ ↗
   ↖ ↘

3. 逆时针旋转 (vx=0, vy=0, ω>0)
   左侧后退，右侧前进
   ↙ ↗
   ↙ ↗

4. 斜向移动 (vx>0, vy>0, ω=0)
   前进+左移的叠加
   ← ↑
   ↖ →
```

```
┌──────┐                          ┌──────────┐
│ ROS2 │                          │  STM32   │

   │                                   │

   │<───────────────────────────────────│
   │                                   │

   │                                   │

   │───────────────────────────────────>│
   │                                   │
   │              ...                  │
```

### 命令格式说明

```
起始符 命令ID  参数(逗号分隔)  结束符
  │      │          │          │
  $    spd:   100,100,100,100  #
  
解析步骤:
1. 检测到起始符 '$'
2. 读取命令ID (到 ':')
3. 读取参数 (到 '#')
4. 分割参数字符串
5. 转换为数值
6. 执行相应命令
```

## 控制循环时序图

```
时间轴 ──────────────────────────────────────────>
       │    │    │    │    │    │    │    │
       ├────┼────┼────┼────┼────┼────┼────┤
      0ms  20ms 40ms 60ms 80ms 100ms...

控制频率: 50Hz (每20ms一次)

每个控制周期:
┌─────────────────────────────────────┐
│  1. 获取当前位置 (TF lookup)         │  ~2ms
│  2. 计算误差                        │  <1ms
│  3. PID计算                         │  <1ms
│  4. 发布速度指令                     │  <1ms
│  5. 坐标转换                        │  <1ms
│  6. 麦克纳姆轮计算                   │  <1ms
│  7. 串口发送                        │  ~2ms
└─────────────────────────────────────┘
总计: ~10ms < 20ms (满足实时性要求)
```

## 重点记忆图示

### PID三要素

```
    Kp (比例)
      ╱│╲
     ╱ │ ╲
    │  │  │
    快  │  震荡
        │
    响应快但不稳定

    Ki (积分)
      ╱│╲
     ╱ │ ╲
    │  │  │
  消除  │  超调
  误差  │
        │
    慢但能达到目标

    Kd (微分)
      ╱│╲
     ╱ │ ╲
    │  │  │
  预测  │  噪声
  趋势  │  敏感
        │
    稳定但怕干扰
```

### 坐标系右手定则

```
       Z (向上)
       │
       │
       └───→ X (前)
      ╱
     ╱
    Y (左)

旋转: 右手拇指指向轴正向,
     四指弯曲方向为正旋转
```
