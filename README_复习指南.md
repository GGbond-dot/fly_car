## 📝 重要公式清单

在考试前务必记住这些公式（详见各文档）：

### 1. PID控制
```
u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt
```

### 2. 坐标旋转（全局→本体）
```
x_local = cos(θ)·x_global + sin(θ)·y_global
y_local = -sin(θ)·x_global + cos(θ)·y_global
```

### 3. 麦克纳姆轮速度
```
v1 = vx - vy - ω(lx+ly)
v2 = vx + vy - ω(lx+ly)
v3 = vx + vy + ω(lx+ly)
v4 = vx - vy + ω(lx+ly)
```

## 💡 学习技巧

### 1. 理解大于记忆
不要死记硬背公式，要理解：
- **为什么**需要这个公式
- **怎样**推导这个公式
- **何时**使用这个公式

### 2. 理论结合实践
- 看代码时对照理论文档
- 学理论时想象实际应用
- 尝试修改参数观察效果

### 3. 绘制思维导图

## 🆘 常见问题

### Q1: 三个文档都要看吗？
**A**: 是的，但可以有侧重：
- 时间充足：三个文档都仔细阅读
- 时间紧张：重点看《期末考试复习资料.md》，用另外两个作为辅助
- 考前冲刺：重点看《快速参考手册.md》

### Q2: 哪些是必考内容？
**A**: 根据文档标注的"重点"和"考试重点"部分，核心必考内容是：
1. PID控制算法
2. 坐标系变换
3. 麦克纳姆轮运动学

### Q3: 需要记住所有代码吗？
**A**: 不需要！重点是：
- 理解代码逻辑
- 知道各模块的功能
- 能看懂代码结构
- 记住关键算法的实现思路

### Q4: 如何高效复习？
**A**: 建议：
1. 第一遍：快速浏览全部文档，了解大纲
2. 第二遍：仔细学习重点章节，做笔记
3. 第三遍：做题练习，查漏补缺
